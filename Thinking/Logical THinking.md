#  Read a problem like a contract 

Before solving the problem we need to indentify 5 things : 

| Part        | Question                                           |
| ----------- | -------------------------------------------------- |
| Input       | What information is given ?                        |
| Output      | what is the desried output ?                       |
| Rules       | What are the conditions which leads to ouput ?     |
| Constraints | What are input rules ? like which input is valid ? |
| Edge Cases  | Which valid case may need special care ?           |
English matters a lot in problme small words like : **at least, at most, greater than, equal to, only if and exactly**
